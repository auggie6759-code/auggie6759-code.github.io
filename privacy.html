Privacy Policy

ATHENA Personal · Last updated: November 3, 2026

Who uses ATHENA

ATHENA Personal is a private assistant used by a single person, its owner and developer. The only Google account it accesses is the owner's own personal Gmail account. It does not collect data about anyone else as users.

Google data accessed

  • https://www.googleapis.com/auth/gmail.readonly: to search and read the owner's messages when the owner asks.
  • https://www.googleapis.com/auth/gmail.send: to send an email only after the owner hears the recipient, subject and full text and explicitly confirms.

ATHENA never deletes, archives, labels or modifies messages and never changes account settings.

How the data is used

Message content is retrieved only in response to the owner's request and is used only to answer that request. To do so, the relevant text is processed by:

  • the Anthropic Claude API, which generates ATHENA's spoken reply; and
  • the ElevenLabs API, which turns that reply into speech when ATHENA reads it aloud.

Gmail data is not sold, not used for advertising, not shared with anyone else, and not used to train or improve generalized AI or machine-learning models.

No person other than the owner reads Gmail data.

Storage and security

  • ATHENA runs on a private server reachable only through the owner's private network; it is not exposed to the public internet.
  • The Google authorization token is stored encrypted (AES-256-GCM). Temporary access tokens exist only in memory.
  • Email content is not written to logs or saved to disk. It stays only in the current conversation, in memory, and is discarded when the conversation ends. The only exception is a specific fact the owner explicitly asks ATHENA to remember, which is stored encrypted and can be deleted on request.
  • No passwords are collected; access uses Google's official OAuth consent.

Google API Services User Data Policy

ATHENA's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deletion

The owner can disconnect Gmail at any time by telling ATHENA "disconnect my Gmail", which revokes the authorization and deletes the stored token, or at myaccount.google.com/permissions.
